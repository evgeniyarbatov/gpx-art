# Architecture

## End-to-end flow

```
SOURCE_DIR (your GPX library)
        │
        ▼
  select subset ── random (make random) or DTW diversity (make dtwselect)
        │
        ▼
     gpx/          working GPX set
        │
        ▼
  gpx-art.py       for each track × each style
        │
        ├─ style function → matplotlib figure
        ▼
   images/         <style>-<track>.png
```

1. Collect GPX files into `gpx/` (random sample or DTW selection from a source directory).
2. Optionally preview tracks with `plot-gpx.py`.
3. Render each GPX file with every registered style in `gpx-art.py`.
4. Write PNGs to `images/`.

## Components

| Path | Role |
|---|---|
| `scripts/gpx-art.py` | Main generator: style registry, rendering |
| `scripts/dtw-select.py` | Diverse GPX selection via FastDTW |
| `scripts/plot-gpx.py` | Visual grid preview of tracks in `gpx/` |
| `scripts/utils.py` | Shared GPX listing and parse helpers |
| `scripts/sample-tracks.py` | Optional: sample personal parquet → GPX |
| `scripts/parquet_tracks.py` | Optional: parquet ingest helpers |
| `gpx/` | Working GPX inputs |
| `images/` | Generated PNG outputs |
| `Makefile` | Public GPX install, select, plot, render, test |
| `make/parquet.mk` | Personal parquet ingest (`art-parquet`) |

## Style system

Styles are plain Python functions registered with a decorator:

```python
@style("scaffold")
def scaffold(lons, lats):
    # draw with matplotlib …
    return fig, bg_color
```

- `STYLES` maps name → callable.
- Each style receives longitude/latitude arrays and returns a figure plus background color.
- `create_art` looks up the style, draws the track, and saves the PNG.
- New styles are added by defining another `@style(...)` function in `gpx-art.py`; no central switch statement.
- `extract_style_source` parses `gpx-art.py` with the AST to pull the full source of a single `@style` function by name.

Path helpers (`flow_path`, `pad_limits`, `ink_stroke`, palettes, etc.) are shared utilities used by many styles.

## Track selection

**Random** (`make random`): `find` + `shuf` + `cp` — simple sample from `SOURCE_DIR`.

**DTW** (`make dtwselect` / `dtw-select.py`):

1. Parse all GPX files in the source directory (or every city parquet).
2. Drop tracks shorter than 10 km.
3. Downsample and normalize trajectories.
4. For parquet, take one qualifying track from each file, then fill remaining slots.
5. Greedily pick a diverse set maximizing FastDTW distance from already chosen tracks and from whatever is already in `gpx/`.
6. Replace `gpx/` with the winners.

## Data layout

- `SOURCE_DIR` (default `./source-gpx`) is the external GPX library; the repo does not ship large source collections.
- `gpx/` and `images/` are working directories regenerated by Make targets.

## Personal parquet source

`make/parquet.mk` is a separate ingest lane (`make art-parquet`). It checkouts a private `[private]` repo, FastDTW-selects ≥10 km tracks from every city parquet, and writes ordinary GPX into the same `gpx/` working set. Render and plot stay GPX-only. Default sample size is 100.

A city parquet is a bundle of tracks (`name`, LineString `geometry`, `city`). Source is the parent folder (`android`, `casio`, `strava`). Those lines are already RDP-simplified at 10 m.
